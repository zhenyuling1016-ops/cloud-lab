关于本站

🗂

它到底是什么

一组纯静态文件（HTML / CSS / JS）。GitHub Pages 把它们当作网站根目录，通过 username.github.io/仓库名/ 的形式对外提供访问。

⚡

“服务器”在哪里

没有我能登录的主机。请求由 GitHub 的边缘节点响应，静态资源被缓存并分发，这就是 Serverless / 静态托管的典型形态。

🔒

为什么选它

免费、无需绑定银行卡、自带 HTTPS 证书、天然具备版本管理（每次 git push 就是一次发布）。

从本地到公网的四步

  1. 1

    创建仓库

    在 GitHub 上新建一个公开仓库，例如 cloud-lab。仓库名会成为 URL 路径的一部分。

  2. 2

    推送页面

    把 index.html、css/、js/ 提交到 main 分支。也可以用网页端 “Add file → Upload files” 直接拖拽上传。

  3. 3

    开启 Pages

    进入 Settings → Pages，Source 选 Deploy from a branch，分支选 main、目录选 / (root)，保存。

  4. 4

    访问验证

    等待约 1 分钟，构建成功后页面顶部会出现访问地址。用浏览器打开即可看到本页。

关于 404 页面

仓库中同时提供了 404.html。GitHub Pages 在找不到资源时会返回它，这算是最小可用的错误处理，也方便后续改造成单页应用的路由回退页。
